图形绘制与面积计算程序 - 参数说明文件

一、程序结构说明：
1. Shape抽象基类：
   - 成员变量：位置(x,y)、颜色(color)、名称(name)
   - 纯虚函数：calculateArea()(计算面积)、draw()(绘制图形)
   - 虚函数：displayInfo()(显示信息)

2. Triangle派生类(三角形)：
   - 特有属性：三边长(a,b,c)
   - 面积计算：使用海伦公式，自动验证三角形有效性
   - 绘制：使用'*'字符绘制三角形轮廓

3. Square派生类(正方形)：
   - 特有属性：边长(side)
   - 面积计算：side * side
   - 绘制：使用'■'字符绘制正方形

4. Circle派生类(圆形)：
   - 特有属性：半径(radius)
   - 面积计算：π * radius^2
   - 绘制：使用'●'和'○'字符绘制圆形

二、参数修改示例：
如需修改图形属性，请在main函数中修改以下代码：

// 创建三角形 - 参数：x坐标, y坐标, 边长a, 边长b, 边长c, 颜色
Triangle triangle(10, 5, 5, 5, 6);    // 默认三角形

// 创建正方形 - 参数：x坐标, y坐标, 边长, 颜色
Square square(20, 10, 4);             // 默认正方形

// 创建圆形 - 参数：x坐标, y坐标, 半径, 颜色
Circle circle(30, 15, 3);             // 默认圆形

三、颜色参数说明：
可修改图形颜色，以下是常用颜色值：
- 7: 白色(默认)
- 10: 绿色(三角形默认)
- 11: 蓝色(正方形默认)
- 12: 红色(圆形默认)
- 13: 紫色
- 14: 黄色
- 15: 亮白色

四、运行说明：
1. 直接运行编译后的程序
2. 程序会自动显示所有图形的信息和面积
3. 程序会以字符形式绘制图形效果
4. 程序计算并显示所有图形的总面积

五、自定义图形添加指南：
如需添加新的图形类型，请：
1. 创建新的派生类，继承自Shape基类
2. 重写calculateArea()和draw()纯虚函数
3. 添加必要的构造函数和成员变量
4. 在main函数中创建对象并添加到shapes数组
