动物类继承与多态演示程序 - 说明文件

一、程序结构说明：
1. Animal基类：
   - 成员变量：gender(性别)、name(名称)
   - 虚函数：soar()(叫声)、eat()(进食)
   - 普通函数：getInfo()(获取信息)

2. Tiger派生类(老虎)：
   - 特有属性：huntingSkill(捕猎技能)
   - 重写soar()：输出"吼吼吼！"
   - 重写eat()：展示捕猎技能

3. Sheep派生类(羊)：
   - 特有属性：woolColor(羊毛颜色)
   - 重写soar()：输出"咩咩咩！"
   - 重写eat()：描述羊毛颜色

二、多态实现：
- 创建基类指针数组，存储不同类型的动物对象
- 通过基类指针调用虚函数，自动识别并执行派生类的实现

三、可修改参数示例：
如需修改动物属性，可在main函数中修改以下代码：

// 创建老虎对象
Tiger tiger1("雄性", "东北虎", "潜伏突袭");
Tiger tiger2("雌性", "孟加拉虎", "快速追击");

// 创建羊对象
Sheep sheep1("雄性", "美利奴羊", "洁白");
Sheep sheep2("雌性", "小尾寒羊", "米黄");

// 修改动物顺序
Animal* animals[4] = {
    &sheep2,  // 可以调整顺序展示不同的执行结果
    &tiger1,
    &sheep1,
    &tiger2
};

四、运行说明：
直接运行编译后的程序，无需用户输入，程序会自动展示所有动物的信息、叫声和进食行为。
